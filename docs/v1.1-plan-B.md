# V1.1 · B 线（Codex）：手机与电脑版式

> 来源：V1.1 双线开发计划 B 线部分，已定稿。A 线（功能）由 Claude 负责，你不要做、不要碰。

## 已拍板
- 断点：手机 <768、平板 768–1023、电脑 ≥1024；mobile-first，`min-width`。
- ≥1024：底部 TabBar → 左侧竖栏（Logo + 三个入口）；768–1023 仍用底栏。
- 01、02 不做左右两栏（需改路由，放 V1.2）；所有宽度单栏，≥768 居中限宽。
- 弹层：<768 底部抽屉；≥768 居中对话框（最大宽 480）或锚点弹层。
- 设计参考里「内容区最大 430 居中」废止；浅色主题、无阴影（浮层除外）、无渐变（hero 保护层除外）继续有效。
- tokens 只可新增布局类变量：`--sidebar-w` `--content-max` `--col-gap`。

## B0 · 版式地基（先做）
- `tokens.css` 新增 `--sidebar-w`、`--content-max`、`--col-gap`；`global.css` 加 `100dvh`、safe-area、`:focus-visible`。
- 新建 `src/styles/layout.module.css`、`src/hooks/layout.ts`（`useBreakpoint()`，只读 `matchMedia`）。
- 验收：390 / 768 / 1280 下现有 6 页无横向滚动、无溢出。

## B1 · 电脑版外壳
- ≥1024 侧栏；<1024 保持底栏；内容区居中，最大宽 `--content-max`。
- Sheet / Dialog / Menu 按上面规则切换；Esc 关闭、点遮罩关闭、焦点陷阱。
- 验收：同一套组件，调整窗口宽度即时切换，无刷新、无状态丢失。

## B2 · 各页电脑版式
- 01、02：单栏，≥768 居中限宽。
- 03：卡片 ≥768 两列、≥1024 三列；文档查看器仍整页打开。
- 04：封面卡网格。05：单列表单居中限宽。06：阅读限宽 + 工具栏固定。
- 导入三步：保持分步，居中限宽。
- 验收：每页 3 个宽度截图存 `docs/shots/`。

## B3 · 交互与无障碍
- hover / focus-visible / active；键盘：Tab 顺序、方向键切换日期、Esc 关闭。
- 触控目标手机 ≥44px；`prefers-reduced-motion`；正文对比度 ≥4.5:1。
- 验收：只用键盘可完成「导入 → 浏览行程 → 打开项目 → 返回」。

## B4 · 套用 A 线新功能的版式（A 线合并后才做）
- A 线新组件（差异区 `DiffSection`、`SourceSheet`、`PhaseCard` 等，以新文件交付）补齐 tablet / desktop 样式。只改样式与 JSX 结构，不改逻辑。

## B5 · 视觉回归与文档
- 扩展 `qa/shoot.py`：390×844、768×1024、1280×800 批量截图。
- 新增 `docs/responsive.md`：断点、布局规则、各组件在各宽度的行为。
- 验收：无阴影 / 渐变 / 深色主题违规，无横向滚动，`npm run build` 通过。
